# 🐉 DragonCraft: Prodigy STEM Realm

An interactive web-based **STEM Role-Playing & Voxel Adventure Game** designed for 9-year-old elementary school learners, blending **Prodigy-style magical dragon spell battles** with **Minecraft-style voxel world exploration, ore mining, monument crafting, and surprise treasure chests**.

## ✨ Core Features
- **🧙‍♂️ Wizard & Crafter Login Portal**: Persistent multi-profile login with secret 4-digit Rune PIN, 4 hero classes (*Redstone Mage, Ender Knight, Aether Alchemist, Emerald Ranger*), and 3 starter dragons.
- **🗺️ Interactive 2D Voxel Overworld Map**: Explore 4 unlockable realms (*Emerald Voxel Woods, Redstone Magma Caverns, Crystal Sky Citadel, Obsidian Ender Keep*), mine glowing STEM Ore Blocks, discover hidden World Chests, and encounter Wild Dragons.
- **⚔️ Prodigy-Style STEM Spell Battles**: Every spell (*Pyro Equation Blast, Redstone Thunder Strike, Emerald Elixir Shield, Dragon Taming Crystal*) is powered by solving Grade 3–5 STEM problems with visual block hints and streak multipliers:
  - Algebraic Equations (`3 × 🐉 + 5 = 20`)
  - Multiplication & Division Arrays
  - Minecraft Voxel Geometry (Area & Perimeter)
  - Alchemist Potion Fractions
  - Elementary Science (States of Matter, Simple Machines, Solar System, Magnetism, Photosynthesis)
  - Redstone Logic Gates & Coding Loops
- **🎁 Treasure Chests & Level-Up Surprises**: Every level-up and unlocked achievement automatically rewards a free animated **Surprise Chest** (*Voxel Crafter, Gilded Prodigy, Redstone Arcane, Mythic Dragon Egg*) containing Dragon Eggs, Voxel Relics, Game Points, and fun STEM facts.
- **🐉 Dragon Sanctuary & Monument Crafting**: Tame 8 unique illustrated dragons, evolve them to boost spell power, and craft Voxel Monuments using mined ores.

## 🚀 Play Instantly or Host Live
1. **Play Locally Right Now**: Open `index.html` in any web browser (Chrome, Safari, Edge, iPad/tablet).
2. **Automatic GitHub Pages Hosting**: Push this repository to GitHub and enable **Settings → Pages → Source: GitHub Actions**. The included `.github/workflows/deploy.yml` workflow automatically publishes the online game.
